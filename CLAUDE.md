# Bat-Computer

App desktop (Tauri 2 + React + TypeScript, Windows) que centraliza os projetos pessoais: uma lista com Start/Stop, logs e cadastro por caminho + comando. Design em `docs/plans/2026-10-24-bat-computer-design.md`.
